How It Works

Kruskal's Algorithm

A greedy algorithm that builds the minimum spanning tree by repeatedly selecting the cheapest edge that doesn't form a cycle.

01

Sort All Edges

Sort all candidate communication links by their installation cost in non-decreasing order. This ensures we always consider the cheapest available option first.

O(E log E)
02

Initialize Disjoint Sets

Create a Disjoint Set (Union-Find) structure where each location starts in its own set. This tracks which sites are already connected.

O(V)
03

Examine Next Edge

Take the next cheapest link from the sorted list. Check if the two endpoints belong to different components using find().

O(α(V)) ≈ O(1)
04

Accept or Reject

If the endpoints are in different sets, accept the link and union() the sets. If they're in the same set, reject it — it would form a cycle.

O(α(V)) ≈ O(1)
05

Repeat Until Done

Continue until V − 1 edges have been accepted (all sites connected) or all edges are exhausted (network is disconnected).

≤ E iterations
06

Output the MST

The selected edges form the Minimum Spanning Tree — the cheapest way to connect all reachable emergency sites.

Total: O(E log V)
kruskal_mst.pseudo 
KRUSKAL-MST(G):
    A ← ∅                              // set of MST edges
    for each vertex v in G.V:
        MAKE-SET(v)                    // each vertex is its own component
    SORT(G.E) by weight              // sort edges in non-decreasing order
    for each edge (u, v, w) in sorted G.E:
        if FIND(u) ≠ FIND(v):        // u and v in different components?
            A ← A ∪ {(u, v, w)}        // accept this edge
            UNION(u, v)                 // merge components
            if |A| = |V| − 1: break   // tree is complete
    return A

Union-Find (DSU)

Disjoint Set with path compression and union by rank for near-constant-time cycle detection.

Edge List

All candidate links stored as (src, dest, cost) tuples, sorted by cost for greedy selection.

Spanning Tree

Exactly V − 1 edges connecting all vertices with the minimum total weight.
